# Весёлый фермер

**ФИО:** Котов Дмитрий 
**Группа:** МБС 601-0-01
**Лабораторная работа:** №4

## Реализованные варианты:
*   **Лабораторная №2, Вариант 9:** Устранение дубликатов (изменение массива инвентаря).
*   **Лабораторная №3, Вариант 7:** Расписание жителей деревни (обработка `input.txt` -> `output.txt`).
*   **Лабораторная №4, Вариант 7:** "Я блин, Бетмен" (ночной лес, туман войны и крик по кнопке R).

## Описание проекта
Программа представляет собой текстовую игру «Весёлый фермер». 
В 4-й лабораторной работе была добавлена процедурная генерация карты в динамической памяти, реализовано перемещение персонажа по карте с проверкой коллизий (стены, деревья, камни) и эффект «Тумана войны» с возможностью раскрытия обзора.
